Overview

Prior to this, users applying for a personal loan through a partner platform were redirected off that platform to complete their application — a jarring handoff that cost conversions. I led building an Embedded PL Lending API stack that let partner platforms host the entire loan application journey natively, as part of InCred's broader D2C Personal Loans initiative.

The challenge

Every redirect to a separate application flow is a point where a user can abandon. For B2B partners distributing InCred's personal loan product, sending users off-platform to finish applying was actively working against conversion — and it made the partner's own product experience feel disjointed.

My approach

  • Designed an API stack that exposed InCred's loan application journey as embeddable building blocks, rather than a single external redirect.
  • Used a Server-Driven UI (SDUI) framework so the same underlying journey could render natively across different partner surfaces (web and app) without a separate rebuild per partner.
  • Worked with Fraud & Risk Analytics to carry the same ML-based risk control layers (SMS Scorecard, Behavioral Data Scorecard) into the embedded flow, so partner-originated loans didn't compromise on NPA performance.
  • Grounded the design in 100+ user interviews and in-house usability sessions, plus structured A/B testing, to validate where in the embedded flow users were dropping off.
This shipped alongside the broader D2C PL rebuild — interoperable web & app journeys via the same SDUI framework — and fed into delivering ~85% of the planned H1/H2 2024 roadmap.

Impact

Embedding the application journey directly into partner platforms cut top-of-funnel drop-off by 30%, turning what had been a leaky handoff into a contained, native experience for partner-originated loans.
